O Swapper é um site voltado para a venda e troca de produtos entre usuários. O projeto foi desenvolvido como Trabalho de Conclusão de Curso (TCC), no qual fui contratado por um grupo de alunos para realizar o desenvolvimento do site, sendo responsável pela implementação da solução. O prazo de desenvolvimento foi de aproximadamente um mês.

Para a construção do sistema, foram utilizadas linguagens de marcação, como HTML e CSS, responsáveis pela estrutura e estilização da interface. A lógica de funcionamento e a integração com o banco de dados foram implementadas utilizando JavaScript e Java. O armazenamento e gerenciamento dos dados foram realizados por meio do MySQL.

O projeto teve como objetivo entregar uma plataforma funcional, aplicando de forma prática os conhecimentos técnicos adquiridos, integrando front-end, back-end e banco de dados de maneira eficiente e organizada.
